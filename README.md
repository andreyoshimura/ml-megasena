​🧠 Mega Engine - ML Research

​Este repositório é o laboratório de Machine Learning da Mega Engine. Aqui são desenvolvidos e testados os modelos de Deep Learning para análise de séries temporais dos sorteios da Mega-Sena.

​🚀 Destaques do Projeto

​Modelagem Preditiva: Uso de Redes Neurais Recorrentes (RNN) e LSTM via Keras/TensorFlow.
​Análise Comparativa: Experimentos comparativos com séries temporais do mercado financeiro (ml-acoes.ipynb).
​Pipeline de Dados: Scripts automatizados para download, limpeza e conversão de resultados oficiais.

​📂 Estrutura de Arquivos

​predict_megasena-keras.ipynb: Treinamento do modelo de Deep Learning.

​predict_megasena.ipynb: Processamento de dados e análise estatística (EDA).

​ml-acoes.ipynb: Estudo de modelos aplicados a ativos financeiros (PETR4).

​resultados_megasena.csv: Base histórica para treino e teste.
